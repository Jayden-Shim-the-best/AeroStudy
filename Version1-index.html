ℹ️ About AeroStudy

What is AeroStudy?

AeroStudy is a student-focused productivity application designed to help students organize their work, focus during study sessions, and understand their study habits.

⏱️ Focus Timer

The timer creates dedicated periods for studying and taking breaks. Study time and break time are tracked separately.

📝 Tasks

Tasks allow students to turn large amounts of schoolwork into smaller, manageable goals.

🎵 Study Atmosphere

AeroStudy can generate simple ambient sounds directly in the browser using the Web Audio API. No music service is required.

💻 How The Code Works

🌐 HTML

HTML creates the structure of AeroStudy, including buttons, pages, timers, task lists, and navigation.

<button>Start Studying</button>

🎨 CSS

CSS controls the appearance of the application. It creates the layouts, colors, animations, responsive design, and dark mode.

.card { border-radius:18px; padding:22px; }

⚙️ JavaScript

JavaScript controls the behavior of the app. It manages timers, tasks, statistics, navigation, XP, and saved data.

setInterval(function() { timeLeft--; },1000);

💾 Local Storage

AeroStudy uses the browser's localStorage to save information so your progress remains available after refreshing the page.

localStorage.setItem("aeroStudyData",JSON.stringify(data));

🔊 Web Audio API

Ambient sound can be created directly by JavaScript using browser audio oscillators. This allows the atmosphere feature to work without an external audio library.
